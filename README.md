# java-lotto-precourse

---
### 3주차 로또 🎟️
- 로또 구매 금액과 당첨 번호를 입력받아, 당첨 내역과 수익률을 계산하는 프로그램
---
### 기능 요구 사항

- 로또 번호 숫자 범위 (1~45)
- 1개의 로또 발행시 중복되지 않은 6개 숫자 뽑음
- 당첨 번호 추첨시 중복되지 않은 숫자 6개 + 보너스 번호 1개
- 당첨은 1~5등까지
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액 입력시, 구입 금액에 해당하는 로또 발행
- 로또 1장 -> 1,000원
- 당첨 번호와 보너스 번호 입력 받음
- 사용자가 구매한 로또 번호와 당첨번호 비교 후 당첨 내역 및 수익률 출력 후 종료
- 잘못된 값 입력시 `IllegalArgumentException` 발생, "[ERROR]"로 시작하는 메세지 출력 후 그 부분부터 다시 입력 받음
  - IllegalArgumentException, IllegalStateException 등 정확히 명시

---
### 입출력 요구 사항

**입력**

1. 로또 구입 금액 입력받음. 
    - 구입 금액은 1,000원 단위로 받음
    - 나누어 떨어지지 않으면 예외 처리
2. 당첨 번호 입력
    - 번호는 쉼표(,) 기준으로 구분
3. 보너스 번호를 입력

**출력**

1. 발행한 로또 수량 및 번호 출력
   - 로또 번호는 오름차순으로 정렬
2. 당첨 내역 출력
3. 수익률은 소수점 둘째자리에서 반올림
    - ex> 100.0%, 51.5%
4. 예외 상황시 에러 문구 출력
    - 에러 문구는 "[ERROR]"로 시작
    - 에러 메세지 출력 후 그 부분부터 다시 입력

---
### 구현 목록

* 로또 구입 금액, 당첨 번호, 보너스 번호를 입력
* 입력된 당첨 번호를 파싱하여 정수 집합(Set)으로 변환
* 중복되지 않은 6개의 로또 번호를 1~45 범위 내에서 랜덤으로 생성
* 구입 금액에 따라 여러 장의 로또를 발행
* 각 로또 번호가 당첨 번호와 몇 개 일치하는지 계산
* 일치 개수와 보너스 번호 여부를 통해 등수(1등~5등)를 판별
* 총 당첨 금액을 기반으로 수익률(%)을 계산
* 구매한 로또 목록과 당첨 통계를 출력

---
### 예외 처리
- `EMPTY_INPUT`: 입력값이 비어 있을 때 발생
- `INVALID_INPUT`: 숫자가 아닌 문자가 입력되었을 때 발생
- `EXCEED_MAX_PURCHASE`: 한 번에 100,000원을 초과하여 로또를 구매하려 할 때 발생
- `INVALID_PURCHASE_UNIT`: 구매 금액이 1000원 단위가 아닐 때 발생
- `NEGATIVE_OR_ZERO_PRICE`: 입력 금액이 0 이하일 때 발생
- `DUPLICATE_WINNING_NUMBER`: 당첨 번호와 보너스 번호가 중복될 때 발생
- `INVALID_NUMBER_RANGE`: 번호가 1~45의 범위를 벗어났을 때 발생
- `INVALID_NUMBER_COUNT`: 당첨 번호의 개수가 6개가 아닐 때 발생
